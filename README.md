# Personal Portfolio Website

## Overview
A responsive personal portfolio website developed using HTML, CSS, and JavaScript to showcase my profile, projects, and contact information.

## Features
- Responsive Navigation Bar
- Home Section
- Projects Section
- Contact Form
- Clean and User-Friendly Interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Projects Included
### Java Application
Desktop application developed using Java Swing and NetBeans.

### Reservation System
Full-stack project developed using JDBC and MySQL for booking management.

### Database Dashboard
Database monitoring dashboard displaying real-time metrics.

## How to Run
1. Download or clone the repository.
2. Open `portfolio.html` in any web browser.
